# HHU Data Science Kurs
Materialien zum Kurs "Data Science" an der HHU Düsseldorf
im 4. Semester Informatik Bachelor

Hier findet sich vor allem:
* Vorlesungsskript (ab 2023)
* Vorlesungsfolien (`slides/`, ab 2026 hier versioniert; Bauanleitung in `slides/README.md`)

Der Kurs ist auf deutsch gehalten.
Vorausgesetzt werden drei Semester Mathematik für Informatiker, dabei entspricht der Stoff etwa Lineare Algebra I, Analysis I und ein bisschen mehrdimensionale Analysis und Anfänge der Stochastik. Aus der Informatik werden Grundlagen und Programmierung vorausgesetzt, nicht jedoch Python.
